What This Demo Is

Dex Tools is a practical DeFi demo built on Ethereum Sepolia. It combines token swaps, liquidity pools, LP token ownership, and farming rewards into one connected on-chain product flow.

This project is designed as a frontend and smart contract showcase rather than a production exchange. Its goal is to demonstrate how wallet identity, AMM logic, reserves, approvals, LP mechanics, and modular frontend architecture can work together in one consistent experience.

Everything here runs on testnet contracts and testnet tokens only, so it can be explored safely without using real funds. The main focus is DeFi product behavior, reusable Web3 UI patterns, and contract-driven frontend implementation.
