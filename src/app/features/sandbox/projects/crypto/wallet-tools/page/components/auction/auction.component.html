Auction

You can get APT token by take a bit in auction pulls. If your bit win then you will get APT after pull timer is end. Then you can spend APT in marketplace and buy any items.

Rules and pulls
  1. You bit only AST Tokens
  2. Minimun 1 AST per bit
  3. If your bit loose then you will get refund AST immediately
  4. Claim reward you can only when pull is end
  1. 3 pulls per day
  2. Only one winner per pull
  3. Each pull can be from 5 min to 1 hour
  4. Pull range from 0.1 APT (min) to 1 APT (max)
