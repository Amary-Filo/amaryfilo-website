AMFI Dex Tools

This is a demo project that showcases the core mechanics of decentralized finance within the AMFI ecosystem on the Ethereum Sepolia testnet. Here you can provide liquidity to token pairs, earn rewards through farming, and experiment with token swaps, experiencing how automated market makers (AMMs) and yield protocols work in practice.


To use the project, you need to install the MetaMask browser extension.
Other wallets will be supported later.
